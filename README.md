This utils directory contains 5 utils: 

    array_list.h : a simple generic array_list implementation
    terminal_screen.h: a way to display array of pixels on the terminal
    parallel_unit.h: a simple interface to create very basic thread pools with POSIX threads
    timerino.h: a stopwatch utility to measure execution times
    polly.h: an extremely primitive way of polling keyboard inputs on the terminal (it's basically a system wide key logger)
